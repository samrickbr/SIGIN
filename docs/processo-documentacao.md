# Processo de Documentação do SIGIN

## 1. Roadmap

Define:

- arquitetura;
- regras;
- decisões;
- escopo;
- dependências.

## 2. Sprint

Define o conjunto de trabalho autorizado.

## 3. Executor

Implementa somente o que foi autorizado.

## 4. Validação

Registrar:

- build;
- testes;
- validações manuais;
- contratos confirmados;
- limitações.

## 5. Fechamento

Registrar:

- resultado;
- commit;
- tag, quando houver;
- arquivos ou áreas relevantes;
- pendências.

## 6. Atualização documental

A documentação deve refletir o estado real do Core.

Não documentar como concluído algo que não foi implementado e validado.

Não transformar uma conversa em decisão arquitetural automaticamente.

Somente decisões consolidadas devem entrar na documentação oficial.
