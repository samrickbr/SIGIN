# Sprints

Esta pasta registra o histórico das Sprints do Core.

Cada Sprint deve, quando aplicável, registrar:

- objetivo;
- contexto;
- escopo;
- o que existe;
- o que será reutilizado;
- o que será evoluído;
- o que será criado;
- decisões;
- critérios de aceite;
- resultado;
- commit ou tag;
- pendências.

Não criar retrospectivamente documentos de Sprints nesta execução.
