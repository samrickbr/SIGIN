# Decisões Arquiteturais

Esta pasta registra decisões arquiteturais consolidadas do SIGIN Core.

Uma decisão arquitetural deve conter:

- contexto;
- problema;
- alternativas consideradas;
- decisão;
- justificativa;
- impacto;
- consequências;
- status.

Não criar arquivos de decisões históricas nesta execução.
