# Execuções

Esta pasta registra o resultado efetivo das implementações realizadas pelo Executor Core.

Cada execução deve registrar, quando aplicável:

- solicitação recebida;
- escopo autorizado;
- alterações realizadas;
- contratos;
- testes;
- build;
- limitações;
- commit;
- branch;
- push;
- pendências.

É obrigatório diferenciar claramente PLANEJADO de EXECUTADO.
